# pdf-imposition-tool
A lightweight, browser-based tool that automates PDF booklet imposition for print designers.

Questo è un semplice tool basato su browser (HTML/CSS/JS) che automatizza la creazione dell'imposition a libretto (booklet) per la stampa. È sufficiente caricare un file PDF a pagine singole comprensivo di abbondanze, esportato dal tuo programma di impaginazione, e il tool calcolerà automaticamente l'impostazione in quartini corretta.

Come si installa: Non è richiesta alcuna installazione. Scarica la cartella contenente i file (index.html, styles.css, app.js) e apri il file index.html direttamente nel tuo browser web.

Come si usa: Trascina o carica il tuo PDF a pagine singole all'interno dell'interfaccia. Il tool genererà immediatamente il nuovo PDF con l'imposition impaginata, pronto per essere mandato in stampa.

//ENG:

This is a simple browser-based tool (HTML/CSS/JS) that automates booklet imposition for printing. Simply upload a single-page PDF with bleeds exported from your layout software, and the tool will automatically calculate the correct printer spreads for you.

How to install: No installation is required. Download the folder containing the files (index.html, styles.css, app.js) and open the index.html file directly in your web browser.

How to Use: Drag and drop or upload your single-page PDF into the interface. The tool will instantly generate a new PDF with the correct imposition, ready for print.
